# E-Commerce GitHub Actions Practice

This repository contains a simple e-commerce website that I am using to
learn and practice **Git, GitHub, GitHub Actions, and CI/CD concepts**.

The main purpose of this repository is learning and hands-on practice.

## 🚀 Project

A simple static e-commerce website built with:

- HTML
- CSS
- JavaScript

The website is hosted using **GitHub Pages**.

## 📚 GitHub Actions Practice

I am using this repository to understand GitHub Actions from the basics.

### Concepts Practiced

- Workflow
- Jobs
- Steps
- Actions
- `runs-on`
- `run`
- `uses`
- `actions/checkout`
- Job dependencies using `needs`
- Environment variables
- GitHub Secrets
- Manual workflow execution using `workflow_dispatch`
- CI/CD workflow structure
- Docker build concepts
- GitHub Pages deployment
